API

Interfaces

class beangulp.Importer

Interface that all source importers need to comply with.

All importers must adhere to this interface. This class provides a default implementation for some of the methods. Importers need to define at least the identify() and account() methods.

property name

Unique id for the importer.

The name is used to identify the importer in the command line interface. Conventionally this is a dotted string containing the module and name of the class, and this is what is returned if this property is not overrided in a subclass, however a specific format is not enforced.

abstract identify(filepath)

Return True if this importer matches the given file.

Parameters

filepath – Filesystem path to the document to be mathed.

Returns

True if this importer can handle this file.

abstract account(filepath)

Return the account associated with the given file.

The account is used to determine the archival folder for the document. While the interface allows returning different accounts for different documents, normally the returned account is a just a function of the importer instance.

Parameters

filepath – Filesystem path to the document being imported.

Returns

An account name.

date(filepath)

Return the archival date the given file.

The date is used by the archive command to form the archival filename of the document. If this method returns None, the date corresponding to the file document modification time is used.

Parameters

filepath – Filesystem path to the document being imported.

Returns

A date object or None.

filename(filepath)

Return the archival filename for the given file.

Tidy filenames or rename documents when archiving them. This method should return a valid filename or None. In the latter case, the file path basename is used unmodified.

Parameters

filepath – Filesystem path to the document being imported.

Returns

The document filename to use for archiving.

extract(filepath, existing)

Extract transactions and other directives from a document.

The existing entries list is loaded from the existing ledger file, if the user specified one on the command line. It can be used to supplement the information provided by the document being processed to drive the extraction. For example to derive the prior state of the inventory.

Parameters

  • filepath – Filesystem path to the document being imported.

  • existing – Entries loaded from the existing ledger.

Returns

A list of imported directives extracted from the document.

static cmp(a, b)

Compare two entries.

This function is used by the deduplicate() method to determine if two entries are similar enough to be considered duplicates.

Parameters

  • a – First entry.

  • b – Second entry.

Returns

True if the entries are deemed duplicates, False otherwise.

deduplicate(entries, existing)

Mark duplicates in extracted entries.

The default implementation uses the cmp() method to compare each newly extracted entries to the existing entries. Only existing entries dated within a 5 days window around the date of the each existing entry (two days prior and two days past) are considered.

Parameters

  • entries – Entries extracted from the document being processed.

  • existing – Entries loaded from the existing ledger.

Returns

A new list of entries where duplicates have been marked setting the __duplicate__ entry metadata field to True.

sort(entries, reverse=False)

Sort the extracted directives.

The sort is in-place and stable. The reverse flag can be set to sort in descending order. Importers can implement this method to have entries serialized to file in a specific order. The default implementation sorts the entries according to beancount.core.data.entry_sortkey().

Parameters

  • entries – Entries list to sort.

  • reverse – When True sort in descending order.

Returns

None.

class beangulp.importers.csvbase.Date(name, frmt='%Y-%m-%d')

Specialized Column descriptor for date fields.

Parse strings into datetime.date objects accordingly to the provided format specification. The format specification is the same understood by datetime.datetime.strptime().

Parameters

  • name – Column name or index.

  • frmt – Date format specification.

class beangulp.importers.csvbase.Amount(name, subs=None)

Specialized Column descriptor for decimal fields.

Parse strings into Decimal objects. Optionally apply regexp substitutions before parsing the decimal number. This allows to normalize locale formatted decimal numbers into the format expected by the decimal.Decimal constructor.

Parameters

  • name – Column name or index.

  • subs – Dictionary mapping regular expression patterns to replacement strings. Substitutions are performed with re.sub() in the order they are specified.

class beangulp.importers.csvbase.Importer(account, currency, flag='*')

CSV files importer base class.

This class provides the infrastructure and the basic functionality necessary for importing transactions and balance assertions from CSV files. To do anything useful it needs to be subclassed to add fields definitions. Fields are defined as class attributes of type Column.

Parameters

  • account – Importer default account.

  • currency – Importer default currency.

  • flag – Importer default flag for new transactions.

extract(filepath, existing)

Implements beangulp.Importer.extract().

This methods costructs a transaction for each data row using the date, narration, and amount required fields and the flag, payee, account, currency, tag, link, balance optional fields.

Transaction metadata is constructed with metadata() and finalize() is called on each transaction. These can be redefine in subclasses. For customization that cannot be implemented with these two extension points, consider basing the importer on CSVReader and implementing the Importer interface with tailored processing of the data rows.
