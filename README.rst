beangulp: Importers Framework for Beancount
============================================

This package provides a framework for importing transactions into a
Beancoount ledger from account statements and other documents and for
managing the associated documents.


This project is the evolution of the ``beancount.ingest`` framework
available in Beancount 2.3. In the unreleased Beancount 3.0
``beancount.ingest`` has been removed in favour of this
package. ``beangulp`` is compatible with both Beancount 2.3 and the
unreleased Beancount 3.0.

Documentation is available in form of code docstrings and
`examples`__.  The `documentation`__ for ``beancount.ingest`` provided
a good introduction and is still partially relevant to ``beangulp``.
The rest of the Beancount deocumentation can be found `here`__.
